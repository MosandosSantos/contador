# eSocial — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Coletar empregados, rubricas e folha mensal e gerar ZIP de XMLs rascunho dos eventos eSocial essenciais (S-1000/S-1010/S-2200/S-1200/S-1299) com `tpAmb=2`.

**Architecture:** Mesmo padrão dos ciclos anteriores: `core/esocial.py` (calcular + gerar XMLs como lista de arquivos), rotas em `modules/esocial.py` (`/esocial` + `/exportar/esocial`), 4 tabelas novas, validador por script.

**Tech Stack:** Flask 3 + Jinja2 + PostgreSQL (psycopg2); XML via `xml.etree.ElementTree`; validadores por script.

**Spec:** `docs/superpowers/specs/2026-09-16-esocial-design.md`

## Task 2: Gerador `core/esocial.py`
- `calcular(folha, rubricas)`: totais por empregado (proventos, descontos, base INSS/IRRF/FGTS pelas flags) e por rubrica; avisos (NIS ausente, folha vazia).
